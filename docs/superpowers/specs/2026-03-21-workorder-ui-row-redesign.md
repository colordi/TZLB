# 工作单页面记录行 UI 改进设计

## 问题描述

当前工作单页面（`/workorder`）的记录表格中，"详细情况描述"输入框与其右侧的"图片 / 删除"列存在视觉不协调：

1. **高度不一致** - 输入框高度为 2.15rem，而图片区域是 4 个小方块堆叠，导致行高不对齐
2. **图片太小** - 4 个正方形小图（约 1.5rem × 1.5rem），缩略图几乎看不清内容
3. **视觉断层** - 删除按钮与图片区域风格不统一，有明显的割裂感

## 解决方案（方案A）

### 设计要点

1. **统一高度**
   - 将输入框改为 textarea，min-height 设为 4rem
   - 图片区和删除按钮使用 `align-items: stretch` 与输入框等高

2. **2×2 图片网格**
   - 4 个图片槽改为 2×2 网格布局
   - 每个图片槽尺寸显著增大（约 2.5rem × 2.5rem）
   - 使用虚线边框提示可上传状态

3. **统一的删除按钮**
   - 删除按钮改为与图片区等高的垂直长条按钮
   - 使用红色边框和 hover 状态，保持警示性
   - 使用垃圾桶 emoji 或 SVG 图标

4. **一致的边框风格**
   - 输入框、图片区、删除按钮使用相同的圆角（0.75rem）
   - 边框颜色和背景色保持一致

### 代码修改范围

仅修改 `frontend/src/components/workorder/RecordTable.vue`：

1. 修改 `.table-stage` 的 grid-template-columns（右侧宽度从 128px 改为 160px）
2. 修改输入框样式（`textarea.table-input`）增加 min-height
3. 重构 `.row-tools` 布局改为 flex
4. 重构 `.thumb-strip` 为 2×2 网格
5. 修改删除按钮样式与图片区等高

### 交互保持不变

- 点击空位上传图片
- 粘贴图片到行
- 点击图片删除
- 删除按钮删除整行

## 验收标准

- [ ] 输入框与图片区高度一致（最小 4rem）
- [ ] 图片槽清晰可见（每个约 2.5rem × 2.5rem）
- [ ] 删除按钮与图片区等高
- [ ] 整体视觉统一，无断层感
- [ ] 响应式布局在移动端正常显示
