# 林业调查工作台（TZLB）前端产品需求文档

## 1. 产品概述

**产品名称**：林业调查工作台（Forest Survey Workbench）

**产品定位**：面向林业管理部门的调查数据管理与可视化平台，用于记录虫害调查数据、管理工作单、在地图上可视化调查点位，并支持导出标准化 Word 工作单。

**技术栈**：Vue 3 + Vue Router 4 + Vite 5 + Leaflet + Lucide Icons

**目标用户**：林业调查局工作人员，包括管理员和外业调查员。

---

## 2. 用户角色与权限

| 角色 | 标识 | 默认路由 | 权限范围 |
|------|------|----------|----------|
| 管理员 | `admin` | `/workorder` | 工单录入 + 调查点位地图 |
| 调查员 | `investigator` | `/map` | 仅调查点位地图 |

---

## 3. 页面结构

### 3.1 登录页（`/login`）

**路由元信息**：`requiresAuth: false`，`hideShell: true`

**功能需求**：
- 用户名/密码表单登录
- "记住我"复选框：勾选后将用户名持久化到 `localStorage`
- "忘记密码"按钮：弹出 Toast 提示联系管理员
- "申请加入"按钮：弹出 Toast 提示联系管理员开通账号
- 登录成功后根据用户角色自动跳转到对应默认路由
- 支持 `redirect` 查询参数：登录后跳转到被拦截前的页面
- 表单验证：用户名/密码不能为空
- 登录中状态：按钮显示"正在登录"并禁用交互

**API 接口**：
- `POST /api/auth/login`：请求体 `{ username, password, remember_me }`，响应 `{ user }`

### 3.2 工单录入页（`/workorder`）

**路由元信息**：`requiredRoles: [admin]`，仅管理员可访问

**页面布局**：左侧边栏 + 右侧主内容区

#### 3.2.1 左侧边栏

**状态卡片**：
- 实时显示当前记录数量
- 带有 "Real-time" 标签和图标

**任务配置面板**：
- **害虫类型**下拉框：`春尺蠖`、`国槐尺蠖`、`美国白蛾`、`其他害虫`
- **统防统治类型**下拉框：根据害虫类型自动匹配
- **统防统治任务**下拉框：根据害虫类型显示预设任务列表
  - 春尺蠖：`2026春尺蠖防治`
  - 国槐尺蠖：`2026国槐尺蠖第一代/第二代/第三代防治`
  - 美国白蛾：`2026美国白蛾第一代防治`
  - 其他害虫：`2026其他害虫防治`

#### 3.2.2 主内容区

**操作工具栏**：
- 页面标题："工作单录入工作台"
- 副标题："复核现场数据后提交。"
- **导入调查数据**按钮：打开调查数据导入弹窗
- **生成工作单**按钮：逐条生成 Word 文件并下载
- **删除所选**按钮：批量删除选中记录（显示选中数量）

**记录表格**（桌面端）：
- 列：序号、调查日期、属地、编号、点位名称
- 支持全选/单选复选框
- 点击行打开详情编辑弹窗
- 验证错误字段标红显示

**记录卡片**（移动端，`≤900px`）：
- 卡片式布局，显示核心字段
- 点击打开详情编辑弹窗

**空状态**：显示"当前单子为空"，引导用户点击导入

#### 3.2.3 记录详情弹窗

- 编辑所有字段（根据害虫类型动态显示不同字段集）
- 字段类型：日期、文本、数字、选择、文本域
- 图片上传（最多 4 张）
- 保存/删除操作
- 验证错误提示

#### 3.2.4 调查数据导入弹窗

- 日期选择器：按调查日期查询
- 查询结果表格：显示候选记录
- 支持全选/单选
- 不同害虫类型显示不同列：
  - 春尺蠖/国槐尺蠖：编号、属地、点位名称、总虫口数、受害程度
  - 美国白蛾：编号、属地、点位名称、绿地性质、危害寄主、受害株数、网幕数量
  - 其他害虫：编号、属地、点位名称、虫害类型、寄主树种、调查结论

**API 接口**：
- `GET /api/survey/candidates?date=YYYY-MM-DD&pest_type=xxx`
- `POST /api/workorder/generate`：请求体包含害虫类型、任务类型、记录数据，响应为 Word 文件 Blob

### 3.3 调查点位地图页（`/map`）

**路由元信息**：`fullBleed: true`，全宽布局

#### 3.3.1 地图工具栏（集成在 App.vue 顶部导航栏）

**地图视图选择器**：
- 下拉切换不同地图视图（如"美国白蛾点位"）
- 视图列表从 API 动态加载

**筛选按钮**：
- 点击打开筛选弹窗
- 显示当前活跃筛选数量徽章
- 筛选字段动态配置（如属地、调查状态）
- 每个字段支持多选
- 应用筛选/清空筛选操作

**图层按钮**：
- 标准地图（OpenStreetMap）
- 卫星地图（Esri + 天地图注记）
- 显示/隐藏编号标注

#### 3.3.2 地图主区域

**底图**：
- 默认卫星地图
- 支持切换到标准地图
- 卫星地图叠加天地图注记瓦片

**点位显示**：
- GeoJSON 点位渲染为圆形标记
- 颜色映射：根据受害程度（无/轻/中/重）显示不同颜色
- 点位聚合：低缩放级别自动聚合相邻点位
- 编号标注：高缩放级别（≥13）显示点位编号
- 最多渲染 100 个标注

**行政区边界**：
- 显示行政区域边界线（橙色）

**图例面板**：
- 左下角显示点位数量和图例
- 鼠标悬停展开，移出收起

**功能按钮组**（右下角浮动按钮）：
- 添加美国白蛾点位
- 实时定位

#### 3.3.3 点位详情抽屉

- 右侧滑入面板
- 显示点位所有属性字段
- 关闭按钮

#### 3.3.4 新增美国白蛾点位抽屉

- 坐标显示（地图点击获取）
- 编号输入（自动大写，正则验证，自动识别属地）
- 点位名称输入（可选）
- 保存/取消操作

**API 接口**：
- `GET /api/map/views`：返回视图列表 `[{ name, columns }]`
- `GET /api/map/views/{name}?filters`：返回 GeoJSON FeatureCollection
- `GET /api/map/views/{name}/filter-options`：返回筛选配置
- `GET /api/map/layers/admin-boundary`：返回边界 GeoJSON
- `GET /api/map/white-moth-sites/code-rules`：返回编号规则
- `POST /api/map/white-moth-sites`：创建新点位

- 品牌标识：林业调查工作台 + Forest Survey Workbench

## 5. 状态管理

### 5.1 mapStore（地图状态）

模块级响应式存储，MapView 写入，App.vue 读取：

| 状态 | 类型 | 说明 |
|------|------|------|
| `ready` | boolean | 地图是否就绪 |
| `views` | array | 可用视图列表 |
| `selectedView` | string | 当前选中视图 |
| `loadingViews` | boolean | 视图加载中 |
| `filterFields` | array | 筛选字段配置 |
| `activeFilters` | object | 当前筛选值 |
| `openFilterMenus` | object | 筛选菜单展开状态 |
| `basemapMode` | string | 底图模式 |
| `showPointLabels` | boolean | 是否显示编号 |
| `loading` | boolean | 数据加载中 |
| `isFilterPanelOpen` | boolean | 筛选面板是否展开 |
| `activeFilterCount` | number | 活跃筛选数量 |

### 5.2 useAuthSession（认证状态）

- `user`：当前用户对象 `{ id, username, display_name, role, is_active }`
- `isAuthenticated`：是否已登录
- `isInitializing`：会话初始化中

### 5.3 useToast（通知状态）

- 全局 Toast 队列
- 支持 `success`、`error`、`info` 方法

---

## 6. 认证与安全

- **登录态**：基于 Cookie 的 `same-origin` 会话
- **路由守卫**：全局 `beforeEach` 检查登录状态和角色权限
- **401 处理**：API 返回 401 时自动跳转登录页
- **本地开发绕过**：`localhost` 环境下自动添加 `X-TZLB-Local-Auth-Bypass` 请求头

## 7. 字段配置（按害虫类型）

### 7.1 春尺蠖 / 国槐尺蠖
必填：调查日期、属地、编号、点位名称、详细情况描述
可选：备注

### 7.2 美国白蛾
必填：调查日期、属地、编号、点位名称、详细情况描述
可选：绿地性质、危害寄主、受害株数、网幕数量、备注

### 7.3 其他害虫
必填：调查日期、属地、编号、点位名称、详细情况描述
可选：地块类型、虫害类型、寄主树种、备注

---

## 8. 响应式断点

| 断点 | 布局变化 |
|------|----------|
| `>900px` | 桌面布局，侧边栏 + 主内容 |
| `≤900px` | 隐藏桌面导航，显示汉堡菜单 |
| `≤760px` | 移动端地图优化，筛选面板底部弹出 |
| `≤640px` | 紧凑品牌标识，卡片堆叠 |

---

## 9. 数据持久化

- `localStorage` 用途：
  - 记住的用户名（`tzlb.rememberedUsername`）
  - 选中的地图视图（`tzlb.map.selectedView`）
- 地图视图选择跨页面保持

---

## 10. 交互细节

- 地图点位点击：打开详情抽屉
- 地图聚合点点击：放大到聚合区域
- 实时定位：使用 `watchPosition` 持续更新，首次定位自动居中
- 表单验证：提交前校验必填项，错误字段标红
- 工作单生成：逐条导出，显示进度（1/N）
- 筛选：应用筛选重新请求数据，清空恢复默认

---

## 11. 非功能性需求

- 地图初始中心：`[39.91, 116.72]`，缩放级别 11
- 点位标注渲染上限：100 个
- 聚合像素半径：34px
- 聚合最大缩放级别：18
- 标注最小显示缩放：13
- 图片上传限制：每条记录最多 4 张
- Toast 自动消失：info/success 2.6s，error 3.6s
